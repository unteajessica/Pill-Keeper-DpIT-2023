# 💊 Pill Keeper

Pill Keeper is a web-based application developed as a group project during the **DpIT Program – 2023 Edition**.

## 📌 About the Project

The application was designed to help users manage medication schedules, prescriptions, and device monitoring in a user-friendly interface.

This project was created as part of the DpIT (Development Program in IT) training program, focusing on collaborative development and gaining hands-on experience.

Presentation Video: https://youtu.be/B_A2EjuvhwY

## 🛠️ Technologies Used

- HTML5
- CSS3 / SCSS
- JavaScript
- jQuery
- Materialize CSS
- Font Awesome
- Owl Carousel
- Slick Slider

## 📂 Project Structure

- `index.html` – Main landing page
- `login.html` / `signup.html` – Authentication pages
- `device.html` / `deviceinfo.html` – Device management
- `livedata.html` – Live data visualization
- `gallery.html` – Media gallery
- `contact.html` – Contact form
- `your-account.html` – User dashboard
- `css/` – Stylesheets
- `js/` – JavaScript files
- `img/` – Images and assets
- `lib/` – Third-party libraries

## 👥 Team Project

This application was developed collaboratively as part of the **DpIT 2023 program**, emphasizing teamwork, frontend development, and UI/UX principles.
